## B90-W2-A5 (WL-135): SLO metric emitter stub

### What was implemented

Created `src/thegent/governance/slo_metrics.py` (207 LOC) with:

- `SloMetric` — dataclass with all 7 schema fields from Wave-1 A4 + `timestamp` (auto UTC ISO) + `source`
- `SloThresholds` — frozen dataclass with green/red thresholds from Wave-1 A4 artifact
- `evaluate()` — module-level function returning per-field `"green"/"yellow"/"red"` status
- `SloEmitter` — class with `emit(metric)` (JSONL append, fail-fast) and `evaluate(metric, thresholds)` methods

Green/yellow/red evaluation logic:

- Lower-is-better metrics (file_loc, function_loc_p95, impl_importers, cross_boundary_import_edges, cli_help_p95_ms, run_command_p95_ms): `<=green_max` → green; `>=red_min` → red; between → yellow
- Higher-is-better metric (decomposition_checkpoint_pass_rate): `>=green_min` → green; `<=red_max` → red; between → yellow

Fail-fast: `SloEmitter.emit` raises `IOError` loudly if write fails; no fallbacks, no silent errors.

Default output path: `.quality/slo-metrics.jsonl` (append mode).
