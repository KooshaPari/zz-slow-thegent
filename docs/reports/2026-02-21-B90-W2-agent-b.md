`crates/thegent-parser/src/lib.rs`. The implementation:

1. Defines `KNOWN_SUFFIXES` constant array matching the Python `ModelSuffix` enum values.
2. Implements `ParsedModelRust` struct with `base_model`, `suffixes`, and `raw` fields.

   Rust function.

plus additional property tests for `has_suffix`, `is_thinking`, `is_free_tier`,
`is_performance_tier`, `is_economy_tier`, `needs_web_search`.
