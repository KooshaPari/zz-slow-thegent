## Key Concepts (Quick Reference)

- **Offer** = provider + model + region + plan (routable unit)
- **Pareto** = non-dominated offers on (speed, cost, quality)
- **Lexicographic** = optimize in order (e.g., quality → cost → speed)
- **Shadow pricing** = 1 / max(remaining_ratio, ε) — prevents quota drain
- **Plan types**: payg, fixed_bucket, daily_quota_bucket, weighted_unit_bucket, prompt_rate_limited, volatile_free, compute_metered
