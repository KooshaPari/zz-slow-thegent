## Top 2 Picks

1. **AgilePlus** (`adopt`): strongest governance and release hygiene (CI matrix, tests wired, changelog, tags, release workflow) with clear fit for spec-driven agent workflows.
2. **mcp-router** (`pilot`): compelling MCP operations product shape and reproducible monorepo setup, but needs stronger explicit automated test evidence and license fit review before full adoption.

## Top 2 Avoids

1. **ruvnet/ruvnet** (`avoid`): not a product implementation repository; lacks build/test/security/release primitives required for adoption decisions.
2. **mcbizmod** (`avoid`): useful domain idea but operationally stale (older commits, no CI/security policy, weak release hygiene) for current production adoption standards.
