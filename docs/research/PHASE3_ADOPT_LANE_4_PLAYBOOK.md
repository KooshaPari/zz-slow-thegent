## Notes

- Keep all Lane 4 adoptions behind explicit feature/policy toggles during Phase 3.
- For AGPL projects, spike as API consumer first; avoid bundling/derivative packaging until legal sign-off.
- All spike tasks should run from dedicated branch worktrees and merge through controlled integration flow.
