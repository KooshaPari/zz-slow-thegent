## Part 10: Documentation Standards

### Recommended Structure

```
project/
├── README.md              # Project overview, quick start
├── CLAUDE.md              # Claude AI agent guidelines (if applicable)
├── docs/
│   ├── architecture/      # Architecture documentation
│   ├── guides/            # User guides
│   ├── reference/         # API reference
│   └── research/          # Research documents
├── QUICK_START.md         # Quick start guide (optional)
└── ARCHITECTURE.md        # Architecture overview (optional)
```

### Documentation Best Practices

1. **README.md** should include:
   - Project purpose and overview
   - Quick start instructions
   - Key features
   - Installation instructions
   - Basic usage examples

2. **Architecture Docs** should include:
   - System architecture overview
   - Component descriptions
   - Data models
   - Integration points
   - Design decisions

3. **Guides** should include:
   - Step-by-step instructions
   - Code examples
   - Troubleshooting
   - Common patterns
