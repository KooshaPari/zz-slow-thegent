## Top 2 Picks

1. **https://github.com/zed-industries/zed** - strongest engineering and release governance; clear rollback and mature CI/release posture.
2. **https://github.com/NevaMind-AI/memU** - best balance of practical utility and operational maturity for agent-memory use cases.

## Top 2 Avoids

1. **https://github.com/bar181/aisp-open-core** - primarily spec/docs repo with weak executable governance, no clear test/release track.
2. **https://github.com/mediar-ai/MCP-server-client-computer-use-ai-sdk** - high-risk domain (computer control) without matching CI/security/release discipline.

## Notes on Method

- Deep-read performed via fresh shallow clones of all scoped repositories.
- Signals derived from repository structure, lockfiles, workflows, changelogs, tags, and README/in-tree governance artifacts.
- GitHub REST API was rate-limited in this environment, so assessments rely on clone-visible evidence.
