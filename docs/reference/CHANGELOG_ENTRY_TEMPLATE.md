# Changelog Entry Template

Use this template when adding changelog items to `CHANGELOG.md` under `## [Unreleased]`.

## Template

```markdown
## [Unreleased]

### Added

- <what was added and why it matters>

### Changed

- <what behavior changed>

### Deprecated

- <what is deprecated and migration note>

### Removed

- <what was removed>

### Fixed

- <what bug was fixed and user impact>

### Security

- <security-relevant change>
```

## Authoring Guidelines

- Write from user impact first, implementation details second.
- Use one item per bullet.
- Prefer present tense.
- Avoid internal-only noise that has no user-facing effect.
- If a section has no items, leave it empty in `CHANGELOG.md`.
