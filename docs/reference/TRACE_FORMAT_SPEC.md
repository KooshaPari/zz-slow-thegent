# Deterministic Replay System — Trace Format Specification\n\n**Version**: 1.0 \n**Status**: Production \n**Last Updated**: 2026-02-18 \n\n---\n\n## Overview\n\nThis document specifies the JSONL trace format used by the deterministic replay system. Traces capture complete execution metadata during agent runs, enabling deterministic replay with mocked LLM calls, regression testing, and forensic analysis.\n\n## Format Overview\n\n### File Format\n\n- **Type**: JSON Lines (JSONL)\n- **Encoding**: UTF-8\n- **One record per line**: Each line is a valid JSON object\n- **Line endings**: Unix-style (`\\n`)\n- **Compression**: Optional gzip compression (`.jsonl.gz`)\n- **Storage**: `~/.thegent/traces/trace-<session_id>.jsonl[.gz]`\n\n### Example Trace File\n\n`jsonl\n{\"type\": \"session\", \"session_id\": \"s-abc123\", \"task_id\": \"task-refactor\", \"model\": \"claude-opus-4.6\", \"provider\": \"anthropic\", \"status\": \"started\", \"start_time\": \"2026-02-18T10:00:00.000000\", \"config\": {\"temperature\": 0.7, \"max_tokens\": 4096}}\n{\"type\": \"tool_call\", \"tool_name\": \"read_file\", \"tool_id\": \"read_file-0\", \"session_id\": \"s-abc123\", \"call_index\": 0, \"inputs\": {\"path\": \"src/auth.py\"}, \"result\": \"# Auth module...\", \"duration_ms\": 150, \"tokens_used\": 200, \"cost\": 0.001, \"status\": \"success\", \"timestamp\": \"2026-02-18T10:00:00.001000\"}\n{\"type\": \"decision\", \"decision_type\": \"routing\", \"reasoning\": \"Code analysis task\", \"choice\": \"claude-opus-4.6\", \"session_id\": \"s-abc123\", \"timestamp\": \"2026-02-18T10:00:00.002000\"}\n{\"type\": \"tool_call\", \"tool_name\": \"bash\", \"tool_id\": \"bash-1\", \"session_id\": \"s-abc123\", \"call_index\": 1, \"inputs\": {\"cmd\": \"pytest tests/\"}, \"result\": {\"stdout\": \"PASSED\", \"stderr\": \"\", \"returncode\": 0}, \"duration_ms\": 3000, \"tokens_used\": 0, \"cost\": 0.0, \"status\": \"success\", \"timestamp\": \"2026-02-18T10:00:03.002000\"}\n{\"type\": \"session\", \"session_id\": \"s-abc123\", \"status\": \"completed\", \"end_time\": \"2026-02-18T10:00:03.500000\", \"total_cost\": 0.001, \"total_tokens\": 200}\n`\n\n---\n\n## Record Types\n\n### 1. Session Record\n\nRecords session start and end.\n\n#### Session Start\n\n`json\n{\n  \"type\": \"session\",\n  \"session_id\": \"s-abc123\",\n  \"task_id\": \"task-refactor-auth\",\n  \"model\": \"claude-opus-4.6\",\n  \"provider\": \"anthropic\",\n  \"config\": {\n    \"temperature\": 0.7,\n    \"max_tokens\": 4096,\n    \"top_p\": 1.0\n  },\n  \"status\": \"started\",\n  \"start_time\": \"2026-02-18T10:00:00.000000Z\",\n  \"metadata\": {\n    \"user_id\": \"user-123\",\n    \"organization_id\": \"org-456\"\n  }\n}\n`\n\n**Fields**:\n- `type` (string, required): Always `\"session\"`\n- `session_id` (string, required): Unique session identifier (e.g., `s-<uuid>`)\n- `task_id` (string, required): Task being executed (e.g., `task-refactor-auth`)\n- `model` (string, required): Model name (e.g., `claude-opus-4.6`, `gpt-5-mini`)\n- `provider` (string, required): Provider name (e.g., `anthropic`, `openai`, `google`)\n- `config` (object, optional): Session configuration (temperature, max\*tokens, etc.)\n- `status` (string, required): `\"started\"` or `\"completed\"` or `\"failed\"`\n- `start_time` (string, ISO 8601): Session start timestamp\n- `end_time` (string, ISO 8601, optional): Session end timestamp (only on completion)\n- `total_cost` (number, optional): Total cost in USD\n- `total_tokens` (number, optional): Total tokens used\n- `total_duration_ms` (number, optional): Total execution time in milliseconds\n- `metadata` (object, optional): Additional metadata\n\n#### Session End\n\nSame as session start, but with `status` = `\"completed\"` and `end_time` set.\n\n---\n\n### 2. Tool Call Record\n\nRecords a single tool invocation.\n\n`json\n{\n  \"type\": \"tool_call\",\n  \"tool_name\": \"read_file\",\n  \"tool_id\": \"read_file-0\",\n  \"session_id\": \"s-abc123\",\n  \"call_index\": 0,\n  \"inputs\": {\n    \"path\": \"src/auth.py\"\n  },\n  \"result\": \"# Auth module\\nclass Auth:\\n    ...\",\n  \"duration_ms\": 150,\n  \"tokens_used\": 200,\n  \"cost\": 0.001,\n  \"status\": \"success\",\n  \"error_msg\": null,\n  \"timestamp\": \"2026-02-18T10:00:00.001000Z\",\n  \"metadata\": {\n    \"provider\": \"local\",\n    \"cache_hit\": false\n  }\n}\n`\n\n**Fields**:\n- `type` (string, required): Always `\"tool_call\"`\n- `tool_name` (string, required): Name of the tool (e.g., `read_file`, `bash`, `llm_call`)\n- `tool_id` (string, required): Unique tool identifier (format: `{tool_name}-{call_index}`)\n- `session_id` (string, required): Parent session identifier\n- `call_index` (integer, required): 0-based index of this call in the session\n- `inputs` (object, required): Tool input parameters (sensitive data will be redacted)\n- `result` (any, required): Tool result/output (will be truncated if >10KB)\n- `duration_ms` (number, required): Execution time in milliseconds\n- `tokens_used` (integer, optional): Token count estimate (0 for non-LLM tools)\n- `cost` (number, optional): Estimated cost in USD\n- `status` (string, required): `\"success\"` | `\"error\"` | `\"timeout\"` | `\"skipped\"`\n- `error_msg` (string, optional): Error message if status is `\"error\"`\n- `timestamp` (string, ISO 8601): When the call was recorded\n- `metadata` (object, optional): Additional metadata (provider, cache status, etc.)\n\n#### Tool Types\n\nCommon tool names:\n- `read_file` — File read operation\n- `write_file` — File write operation\n- `bash` — Bash command execution\n- `llm_call` — LLM/Claude/GPT API call\n- `api_call` — External API call\n- `glob` — File globbing/searching\n- `grep` — Content search\n- `mcp_call` — MCP tool invocation\n\n#### Result Truncation\n\nIf a result exceeds 10KB, it will be truncated and marked:\n\n`json\n{\n  \"result\": {\n    \"_truncated\": true,\n    \"data\": \"original result up to 10KB...\",\n    \"original_size\": 50000\n  }\n}\n`\n\n#### Sensitive Data Redaction\n\nSensitive input fields are automatically redacted:\n\n`json\n{\n  \"inputs\": {\n    \"api_key\": \"***REDACTED***\",\n    \"password\": \"***REDACTED***\",\n    \"token\": \"***REDACTED***\",\n    \"url\": \"https://api.example.com\"\n  }\n}\n`\n\nRedacted fields:\n- `api_key`, `api_token`\n- `password`, `pwd`\n- `secret`, `auth_token`\n- `bearer`, `authorization`\n- `user_email`, `email`\n- `credit_card`, `cc_number`\n- `ssn`, `social_security`\n\n---\n\n### 3. Decision Record\n\nRecords a decision point in execution (routing, classification, fallback).\n\n`json\n{\n  \"type\": \"decision\",\n  \"decision_type\": \"routing\",\n  \"reasoning\": \"Task involves code analysis - using high-capability model\",\n  \"choice\": \"claude-opus-4.6\",\n  \"session_id\": \"s-abc123\",\n  \"timestamp\": \"2026-02-18T10:00:00.002000Z\",\n  \"metadata\": {\n    \"confidence\": 0.95,\n    \"alternatives\": [\"claude-sonnet-4.5\", \"gpt-5-mini\"]\n  }\n}\n`\n\n**Fields**:\n- `type` (string, required): Always `\"decision\"`\n- `decision_type` (string, required): Type of decision\n - `\"routing\"` — Provider or model routing\n - `\"classification\"` — Content or task classification\n - `\"override\"` — User or policy override\n - `\"fallback\"` — Fallback activation\n- `reasoning` (string, required): Explanation for the decision\n- `choice` (string, required): The choice made\n- `session_id` (string, required): Parent session identifier\n- `timestamp` (string, ISO 8601): When the decision was recorded\n- `metadata` (object, optional): Additional metadata (confidence, alternatives, etc.)\n\n---\n\n## Data Types\n\n### Timestamps\n\n**Format**: ISO 8601 with microseconds \n**Example**: `2026-02-18T10:00:00.123456Z` \n**Timezone**: UTC (Z suffix)\n\n### Costs\n\n**Format**: Floating-point USD \n**Example**: `0.001` (1/1000 USD) \n**Precision**: 6 decimal places\n\n### Durations\n\n**Format**: Milliseconds (ms) \n**Example**: `150.5` (150.5 milliseconds) \n**Range**: Non-negative floats\n\n### Input/Output Serialization\n\n**Rule**: All input and result objects must be JSON-serializable. \n**Handling non-JSON types**:\n- Bytes: Base64 encode\n- datetime: ISO 8601 string\n- UUID: String representation\n- Custom objects: Serialize to dict with `__dict__` or custom encoder\n\n---\n\n## Validation\n\n### Record Structure Validation\n\nEvery record must pass:\n\n1. **JSON validity**: Valid JSON syntax\n2. **Field presence**: All required fields present\n3. **Type correctness**: Fields match expected types\n4. **Value validity**: Fields contain valid values\n\n### File-Level Validation\n\n1. **Line integrity**: Each line is a valid JSON object (no streaming objects)\n2. **Record ordering**: Sessions start before first tool call, end after last\n3. **Call index uniqueness**: Tool call indices are 0-based and unique within session\n4. **Checksum**: Optional SHA256 checksum for corruption detection\n\n### Example Validation Errors\n\n`\nLine 1: Invalid JSON syntax\nLine 5: Missing required field 'tool_name' in tool_call record\nLine 10: Invalid status 'unknown' (expected: success|error|timeout|skipped)\nLine 15: Negative duration_ms (-100)\nLine 20: Duplicate call_index 5 (already seen at line 10)\n`\n\n---\n\n## Compression\n\n### GZIP Compression\n\nTrace files can be compressed to reduce storage:\n\n`bash\n# Manual compression\ngzip trace-s-abc123.jsonl  # Creates trace-s-abc123.jsonl.gz\n\n# Manual decompression\ngunzip trace-s-abc123.jsonl.gz  # Creates trace-s-abc123.jsonl\n`\n\n### Compression Ratio\n\n- **Typical ratio**: 30-50% of original size\n- **Best case**: 10-20% for repetitive data (many similar tool calls)\n- **Worst case**: 95-100% for already-compressed data (binary results)\n\n### Storage Requirements\n\n- **Per session**: 100KB - 10MB uncompressed\n- **Compressed**: 30-100KB typical\n- **Total storage quota**: Default 10GB per workspace\n- **TTL cleanup**: Default 7 days\n\n---\n\n## Best Practices\n\n### For Recording\n\n1. **Always start session**: Call `record_session_start()` at beginning\n2. **Always end session**: Call `record_session_end()` even on error\n3. **Use async recording**: Non-blocking to minimize overhead\n4. **Redact sensitive data**: Automatic for known patterns\n5. **Truncate large results**: Automatic for >10KB results\n6. **Estimate costs**: Provide token and cost estimates\n7. **Use meaningful tool names**: Standard names enable replay compatibility\n\n### For Replay\n\n1. **Validate traces**: Use `TraceValidator.validate_jsonl_file()` before replay\n2. **Handle missing records**: Implement fallback behavior (mock/live/error)\n3. **Preserve determinism**: Use mocked LLM calls only\n4. **Log divergences**: Track differences from original trace\n5. **Report confidence**: Classify changes as deterministic or non-deterministic\n\n### For Storage\n\n1. **Compress traces**: Use GZIP to save storage\n2. **Archive old traces**: Move to cold storage after TTL\n3. **Encrypt at rest**: Recommended for sensitive data\n4. **Monitor quota**: Set alerts for high usage\n5. **Clean up regularly**: Run TTL cleanup job daily\n\n---\n\n## Migration &
