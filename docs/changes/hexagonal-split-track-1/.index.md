## 🏗️ Architecture Highlights

**Final state after Track 1:**

```
thegent (thin layer)
  ↓ HTTP
CLIProxy localhost:8317
  ├─ /v1/routing/select → Pareto routing
  ├─ /v1/auth/oauth/refresh → Token mgmt
  ├─ /v1/quota/check → Quota enforcement
  ├─ /v1/translate/acp → Provider adapters
  └─ /v1/models → Metadata
  ↓
Providers (OpenAI, Anthropic, Gemini, etc.)
```

**Key decisions:**

1. Port Pareto to Go (not FFI) → simpler, faster
2. HTTP endpoints (not lib imports) → decoupled
3. OAuth in CLIProxy → centralized
4. Translators in CLIProxy → reusable
5. Quota in CLIProxy → prevents overruns
6. Parity testing → verify before deletion
7. Separate process → scales independently

See **TRACK1_ARCHITECTURE_DECISIONS.md** for full rationale.
